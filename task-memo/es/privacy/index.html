Politica de Privacidad

Task Memo guarda tus notas y tareas localmente en tu dispositivo.

Recopilacion de datos

Task Memo usa Firebase Analytics y Firebase Crashlytics para entender el uso de la app, mejorar la fiabilidad y diagnosticar fallos. Estos servicios pueden recopilar datos de interaccion con el producto, eventos de apertura y uso de funciones, informacion tecnica del dispositivo y de la app, e informes de fallos.

No usamos identificadores publicitarios ni usamos estos datos para rastrearte en apps o sitios web de otras empresas.

Datos en tu dispositivo

Las notas de voz, audio, transcripciones y tareas se guardan localmente. Task Memo no envia a Firebase texto de notas, audio, transcripciones, tareas ni recordatorios.

Resumen para App Store

Task Memo puede recopilar diagnosticos y datos de interaccion con el producto o analitica de uso mediante Firebase. No se usa seguimiento. No se recopila contenido del usuario, texto de notas, audio, transcripciones, recordatorios, informacion de contacto, ubicacion, fotos ni identificadores introducidos en la app.

Microfono y reconocimiento de voz

El microfono se usa solo cuando empiezas a grabar. El reconocimiento de voz usa servicios del sistema de Apple.
