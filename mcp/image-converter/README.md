# Private Image Converter MCP

Open a client-side image conversion workspace for supported browser formats.

<!-- mcp-name: io.github.KamnevVladimir/image-converter -->

- Remote: `https://kamnevapps.com/mcp/image-converter`
- Transport: Streamable HTTP
- Privacy boundary: selected images, previews, and converted outputs stay in the interactive client workspace.
- Limitation: codec availability varies by browser; the endpoint does not claim to convert a file remotely.
- Canonical tool: `https://kamnevapps.com/tools/image-converter/`
