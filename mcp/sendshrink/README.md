# SendShrink MCP

Compress one supported image toward a stated size limit in an interactive client workspace.

<!-- mcp-name: io.github.KamnevVladimir/sendshrink -->

- Remote: `https://kamnevapps.com/mcp/sendshrink`
- Transport: Streamable HTTP
- Inputs: one JPEG, PNG, or WebP, subject to the limits returned by the tool.
- Privacy boundary: the selected image, preview, and output stay in the interactive client workspace.
- Limitation: compression is best effort; a destination may also enforce dimensions, format, metadata, naming, or account rules.
- Canonical tool: `https://kamnevapps.com/tools/compress-photo-to-size/`
