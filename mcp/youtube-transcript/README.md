# YouTube Transcript Prep MCP

Clean and package caption text that the user has already copied from a transcript panel.

<!-- mcp-name: io.github.KamnevVladimir/youtube-transcript -->

- Remote: `https://kamnevapps.com/mcp/youtube-transcript`
- Transport: Streamable HTTP
- Privacy boundary: pasted transcript text and generated context packs stay in the interactive client workspace.
- Limitation: this tool does not download video or audio, transcribe speech, retrieve captions from a URL, or bypass video access controls.
- Canonical tool: `https://kamnevapps.com/tools/youtube-transcript/`
