# Metadata Remover MCP

Open a client-side workspace to inspect EXIF/GPS and create a cleaned photo copy.

<!-- mcp-name: io.github.KamnevVladimir/metadata-remover -->

- Remote: `https://kamnevapps.com/mcp/metadata-remover`
- Transport: Streamable HTTP
- Privacy boundary: selected file bytes, previews, metadata values, and output stay in the interactive client workspace.
- Limitation: support depends on the browser and input format; the server does not accept a private photo upload for remote processing.
- Canonical tool: `https://kamnevapps.com/tools/remove-photo-metadata/`
