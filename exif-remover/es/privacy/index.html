Política de privacidad

Borrar EXIF funciona de forma local: revisa y limpia metadatos de fotos y vídeos seleccionados en el dispositivo.

Procesamiento de fotos y vídeos

Los archivos seleccionados se procesan en el dispositivo. Fotos, vídeos, nombres de archivo, datos GPS, datos de cámara, metadatos y copias limpias no se suben a nuestro servidor.

Originales

Los archivos originales nunca se sobrescriben. Al guardar o compartir, la app crea copias limpias.

Cuenta, nube e IA

No se requiere cuenta. No se usa sincronización en la nube para procesar medios. La eliminación de metadatos no se realiza mediante IA ni API externas.

Diagnóstico de Firebase

Firebase Analytics y Crashlytics pueden usarse para mejorar fiabilidad y diagnosticar fallos. No reciben tus fotos, vídeos, nombres de archivo, GPS, datos de cámara, metadatos ni copias limpias.

Compras

Adapty se usa para compras dentro de la app, estado Pro y restauración de compras. Borrar EXIF no envía contenido de fotos o vídeos a Adapty.

Soporte

Si contactas con soporte, recibimos solo lo que decides enviar: email, mensaje y detalles diagnósticos opcionales. Las fotos y vídeos no se adjuntan automáticamente.
